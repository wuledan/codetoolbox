# CodeToolbox 🛠️

面向开发者的在线代码工具集平台。所有工具在浏览器端运行，不上传服务器，保护隐私。

## 🚀 技术栈

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS 4 + shadcn/ui
- Vercel Deployment

## 📦 启动

```bash
npm install
npm run dev
```

## 🧰 已实现工具（15个）

### 格式化工具
- **JSON 格式化器** — 格式化/校验 JSON，支持缩进和排序键
- **代码格式化** — JS/TS/CSS/HTML/JSON 美化
- **SQL 格式化** — 15种数据库方言支持

### 编解码工具
- **Base64 编解码** — 文本/图片的 Base64 编码
- **URL 编解码** — 支持 Component 模式
- **HTML 转义** — 特殊字符转义/反转义
- **JWT 解码器** — 解析 JWT Token

### 测试工具
- **正则测试器** — 实时匹配高亮
- **文本差异对比** — 并排/行内模式
- **Markdown 预览** — 实时渲染

### 生成工具
- **UUID 生成器** — v1/v4/v7，批量生成
- **时间戳转换** — Unix/ISO/本地时间互转

### 转换工具
- **YAML ↔ JSON** 互转
- **JSON ↔ CSV** 互转
- **颜色转换** — Hex/RGB/HSL
